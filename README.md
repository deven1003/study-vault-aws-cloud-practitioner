# ☁ AWS Cloud Practitioner (CLF-C02) Study Vault

A free, complete prep hub for the AWS Certified Cloud Practitioner (CLF-C02) exam.

**Live site:** https://deven1003.github.io/study-vault-aws-cloud-practitioner/

## What's inside

- **Core topics** across the exam domains
- **Interactive AWS global architecture** (regions, AZs, edge locations)
- **Exam-style Q&A** and a **timed practice exam**
- **Hands-on labs:** launch an EC2 instance, host a static site on S3, set up IAM users/groups/policies, build a VPC with public and private subnets, deploy a Lambda function, create CloudWatch and billing alarms
- **Cheat sheet:** compute, storage, databases, networking, security and compliance, pricing and billing, the 6 Well-Architected pillars, support plans
- **Downloadable cheat sheet PDF**

## Run locally

Everything is in a single `index.html`, so there's no build step:

```sh
git clone https://github.com/deven1003/study-vault-aws-cloud-practitioner.git
cd study-vault-aws-cloud-practitioner
# open index.html in your browser
```
